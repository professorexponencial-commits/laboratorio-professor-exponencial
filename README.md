# Laboratório do Professor Exponencial

Repositório único para os laboratórios de todas as aulas dos seis módulos do curso **Professor Exponencial**.

## Site

- Página inicial: `index.html`
- Módulo 01, Aula 01: `modulo-01/aula-01/index.html`
- Próximas aulas: `modulo-01/aula-02/index.html`, `modulo-01/aula-03/index.html` etc.
- Próximos módulos: `modulo-02/aula-01/index.html` até `modulo-06/...`

## Publicação

Configurar no repositório: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

O link de exemplo da página inicial, depois da publicação, será:
https://professorexponencial-commits.github.io/laboratorio-professor-exponencial/

Aula 01 do Módulo 01:
https://professorexponencial-commits.github.io/laboratorio-professor-exponencial/modulo-01/aula-01/

## Como publicar novas aulas

1. Crie no repositório `modulo-XX/aula-YY/index.html`.
2. Atualize o `index.html` da página inicial, acrescentando o botão para a nova aula.
3. Mantenha as aulas anteriores no lugar, preservando os links utilizados na Hotmart.

## Privacidade e registros

As páginas do GitHub Pages são públicas. O preenchimento fica no navegador do professor, sem conta e sem banco de dados remoto. Recomendamos que cada professor salve o backup oferecido pela própria atividade, porque outro aparelho/navegador não terá automaticamente esses registros.
